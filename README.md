# Armario

App personal para llevar el armario en el móvil: catálogo de prendas, fichas y combinaciones.

Aquí solo está el programa. Las prendas y sus fotos se guardan dentro de cada aparato y no se publican. Si se conecta la nube, se guardan además en un repositorio privado del dueño, para que el móvil y el ordenador se pongan al día solos.
